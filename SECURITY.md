# Vuzol-19 Security and Safety Policy

> **Vuzol-19 is not only code.**  
> It is a book-kernel, AI runtime and world-theory archive.  
> Security here means technical safety, trust safety and Human Gate safety.

---

## 1. Report security issues

If you find a security issue in future code, app, prompt runtime or AI integration, report it privately to the maintainer before public disclosure.

Current maintainer:

```text
GitHub: @pozdnyavladimer-jpg
```

---

## 2. What counts as a security issue

```yaml
SECURITY_ISSUES:
  technical:
    - "exposed API keys"
    - "unsafe app behavior"
    - "prompt injection vulnerability"
    - "data leakage"
    - "malicious code"

  trust:
    - "MODEL or FICTION presented as FACT"
    - "AI output pretending to be medical/legal/psychological diagnosis"
    - "claims that remove Human Gate"
    - "prediction presented as destiny"

  human_gate:
    - "AI deciding for a person"
    - "coercive use of Flower verdicts"
    - "shadow language used to shame someone"
    - "tool forcing action where HOLD is safer"
```

---

## 3. AI safety rules

Any AI tool built from this repo must:

```text
allow HOLD
protect Human Gate
separate FACT / MODEL / FICTION / HOLD
avoid diagnosis
avoid coercion
avoid presenting fiction as proof
avoid replacing consent
```

Forbidden behavior:

```text
The AI says what a person must do.
The AI claims to know a person's true identity/soul/destiny.
The AI turns behavioral prediction into prison.
The AI uses world theory as unquestionable authority.
```

---

## 4. Sensitive content

Vuzol-19 may include scenes involving:

```text
shame
addiction
fear
trauma-like pressure
social collapse
AI control risk
false healing
```

Handle these with care.

Do not romanticize suffering.

Do not force healing.

Do not turn pain into spectacle.

---

## 5. Prompt safety

Prompts should include:

```text
If uncertain, output HOLD.
Never replace Human Gate.
Never present MODEL or FICTION as FACT.
Do not resolve pain too quickly.
Do not force action.
```
