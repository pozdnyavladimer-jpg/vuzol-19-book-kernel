## 2. Що означає Квітка на схемі

Квітка — це не прикраса.

У “Вузлі-19” вона означає:

```text
поле можливостей
→ розклад через пелюстки
→ перевірка наміру
→ схлопування в Bindu
→ дія або блок
```

Коротко:

> **Квітка показує не те, що вже сталося.  
> Квітка показує, що може стати дією.**

## 3. Центр / Bindu

Центр схеми — це **Bindu**.

```yaml
BINDU:
  meaning: "Human Gate / verdict / центр рішення"
  asks:
    - "Хто зараз хоче діяти?"
    - "Чи це людина, тінь, страх, PRION або система?"
    - "Чи має ця можливість право стати 3D?"
  verdicts:
    - ALLOW
    - REWRITE
    - BLOCK
    - HOLD
    - REROUTE
```

Bindu не генерує дію.  
Bindu вирішує, чи дія має право пройти.

Фраза:

> **Центр не створює сцену.  
> Центр не дає сцені збрехати.**

---

## 4. Шість пелюсток

Шість кольорових точок або напрямів читаються як шість ролей.

```yaml
PETALS:
  violet_mage:
    role: "можливість / бачення / майбутній перехід"
  orange_archer:
    role: "рух / вектор / сцена"
  yellow_engineer:
    role: "структура / технологія / механіка"
  blue_guardian:
    role: "закон / межа / Human Gate"
  green_healer:
    role: "баланс / контакт / return_to_zero"
  red_tank:
    role: "тиск / тіло / біль / виживання"
```

Це не “класи персонажів”, а **лінзи**, через які AI перевіряє сцену.

---

## 5. Гексаграма

Гексаграма формується, коли два трикутники проходять перевірку.

### Верхній / активний трикутник

```text
violet_mage → orange_archer → yellow_engineer
можливість → рух → форма
```

Це **+3 forward**.

Він питає:

```text
Що може народитися?
Куди це рухається?
Яка структура дає цьому тіло?
```

### Нижній / стабілізуючий трикутник

```text
blue_guardian → green_healer → red_tank
закон → баланс → тіло
```

Це **-3 backward**.

Він питає:

```text
Чи є право на дію?
Чи є return_to_zero?
Хто витримає тиск?
```

Фраза:

> **Гексаграма не була символом.  
> Вона була доказом, що намір пройшов шість сторін реальності й не збрехав жодній.**

## 6. Кола

Кола на схемі означають **можливі стани до схлопування**.

До Bindu сцена може бути:

```text
допомогою
насильним спасінням
терапією
PRION
втечею
дією
блоком
паузою
```

Коло — це “ще не commit”.

Фраза:

> **Поки Bindu не дав verdict, форма ще не має права називати себе дією.**

---

## 7. Перетини

Перетини кіл — це місця, де виникає:

```text
конфлікт
резонанс
тінь
false-green
audit
нова можливість
```

У сцені це момент, де герой може помилково схлопнути сенс.

Наприклад:

```text
спокій міста
+
приглушений біль
=
FALSE_GREEN
```

або:

```text
бажання допомогти
+
відсутність згоди
=
насильне спасіння
```

## 8. Як AI має читати схему

AI не має просто описувати зображення.

AI має використовувати його як маршрут:

```yaml
VISUAL_RUNTIME:
  1_center:
    ask: "Де Human Gate?"
  2_forward_3:
    pass:
      - violet_mage
      - orange_archer
      - yellow_engineer
  3_backward_3:
    pass:
      - blue_guardian
      - green_healer
      - red_tank
  4_bindu:
    verdict: "KEEP | REWRITE | BLOCK | HOLD | REROUTE"
  5_memory:
    write: "що сцена навчила систему?"
```
