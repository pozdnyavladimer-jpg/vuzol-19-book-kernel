## 1. What this repository is

## 6. Runtime flow

Every generated scene should pass this flow:

```yaml
SCENE_RUNTIME:
  1_parse_request:
    meaning: "understand what the author asked"

  2_preserve_unknown:
    meaning: "do not invent missing canon as fact"

  3_memory_replay:
    meaning: "find similar shadows, scenes, blocked actions"

  4_find_center:
    meaning: "what is the human nerve of the scene?"

  5_forward_3:
    violet_mage: "possibility / image / future"
    orange_archer: "movement / scene vector / action candidate"
    yellow_engineer: "technology / mechanism / interface"

  6_backward_3:
    blue_guardian: "law / Human Gate / boundary"
    green_healer: "contact / return_to_zero / healing"
    red_tank: "body / pressure / cost"

  7_shadow_audit:
    meaning: "what hidden impulse wants action?"

  8_optional_phase_audit:
    planetary_resource_clock: "what resource is active?"
    mayan_memory_clock: "what replay phase is active?"

  9_bindu_verdict:
    options:
      - KEEP
      - REWRITE
      - BLOCK
      - HOLD
      - REROUTE

  10_write_scene:
    meaning: "only after verdict"

  11_post_scene_audit:
    meaning: "check false-green, Human Gate, pain, consequence"

  12_memory_update:
    meaning: "record what the system learned"
```

## 7. Bindu verdicts

```yaml
KEEP:
  meaning: "scene may be written or kept"

REWRITE:
  meaning: "scene has value, but form is wrong"

BLOCK:
  meaning: "scene violates Human Gate, romanticizes pain or lets PRION pass"

HOLD:
  meaning: "not enough information; Unknown must be preserved"

REROUTE:
  meaning: "change POV, scene type, petal route or structure"
```

## 11. Anti-PRION law

PRION is not simple evil.

PRION is a beautiful wrong form that passes without audit.

```text
beautiful explanation
+ missing Human Gate
+ no return path
+ ignored body signal
= PRION
```

False-green means:

```text
looks stable
looks healing
looks kind
looks correct
but hides pain, Unknown or Human Gate loss
```

Core warning:

> **The most dangerous lie in Vuzol-19 is not darkness.  
> It is a green status that cannot hear pain.**
