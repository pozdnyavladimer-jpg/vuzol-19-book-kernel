# 04 — Дві хвилі ±3, стовпи та межі спостереження

## Чистий хвильовий експеримент

$$\psi_{+}(\theta)=e^{i3\theta},\quad \psi_{-}(\theta)=e^{-i3\theta}.$$

Шість рівних стовпів:

$$\theta_k=k\pi/3,\quad k=0,1,...,5.$$

На цих точках:

$$\psi_{+}(\theta_k)=\psi_{-}(\theta_k)=(-1)^k.$$

**Висновок:** за таким дискретним комплексно-фазовим зчитуванням колонки матриці вимірювання збігаються (`rank=1` замість `rank=2`). Це **aliasing / неспостережуваність конкретних двох мод**, незалежно від швидкості датчика.

## Як відновити спостережуваність

- додати датчики на інших азимутах (наприклад +30°) **з комплексно-фазовим зчитуванням**;
- використати когерентний опорний канал/гетеродин або додаткові інтерференційні вимірювання;
- змінити напрямок/моду збудження;
- застосувати калібрування, незалежний еталон і перевірку фазового дрейфу.

**Важливо:** датчики, що вимірюють тільки інтенсивність `|ψ|²`, не відрізнять ці дві ідеальні моди навіть у зміщених точках, бо для обох `|ψ|²=1`.

## Рухома світлова «квітка»

За інтерференції двох когерентних мод:

$$I(\theta,\varphi)=4A^2\cos^2(3\theta-\varphi/2).$$

При зміні відносної фази `φ` максимум зміщується на `Δθ=Δφ/6`, що виглядає як обертання шестипелюсткового візерунка без механічного ротора. Це не будова електрона.

## Модель вимірювання

Нехай `y = M(R) a + b + η`, де `a` — невідомі коефіцієнти фазових мод, `M(R)` — відповідь сенсорів після зміни орієнтації `R`, `b` — дрейф/зміщення калібрування, `η` — шум.

Якщо `rank(M) < число_невідомих`, Bindu мусить дати `HOLD`, активувати додатковий незалежний метод або переорієнтацію з еталоном. Поворот сам по собі не доводить, що зміна походить від приладу чи від атома.
