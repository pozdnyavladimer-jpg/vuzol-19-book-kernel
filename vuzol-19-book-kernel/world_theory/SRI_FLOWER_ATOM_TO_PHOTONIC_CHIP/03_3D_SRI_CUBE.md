# 03 — Тривимірний Sri Cube: шість портів і допустимі повороти

## Розрізняємо два поняття куба

**World Theory, файл №83:** координати `X = напрямок зв'язку`, `Y = фазові ворота`, `Z = октава/роль матеріалу`. Це **простір ознак**, а не обов'язково три фізичні просторові координати.

**Геометричний 3D-куб досліду:** три звичайні просторові осі x,y,z; шість граней `±X, ±Y, ±Z`; 24 власні обертання куба. Фазовий і октавний стан зберігаються як окремі змінні, щоб не плутати з просторовим обертанням.

## Геометрія датчиків

```text
Port +X: ( 1, 0, 0)    Port -X: (-1, 0, 0)
Port +Y: ( 0, 1, 0)    Port -Y: ( 0,-1, 0)
Port +Z: ( 0, 0, 1)    Port -Z: ( 0, 0,-1)
```

Нехай молекула має нормовані напрямні вектори зв'язків `u_i` і ваги `w_i`; `R` — матриця просторового повороту, `n_j` — напрямок порту. Простий **навчальний**, не спектроскопічний відгук:

$$g_j(R)=\sum_i w_i\,[\max(0,n_j\cdot Ru_i)]^2.$$

Якщо змінювати `R` **лише як математичну систему координат, одночасно обертаючи порти**, фізичних змін немає. Дійсно новий вимір виникає, коли змінюється **відносна орієнтація** молекули та портів/поля.

## Дві групи трьох напрямків

```text
+3: +X, +Y, +Z
−3: −X, −Y, −Z
```

Це одна можлива інтерпретація шести напрямків Квітки в 3D. Інша — два незалежні контури навколо різних площин. Не переносити без доказу плоскі трикутники на геометрію руху електрона.

## Інваріанти

- довжини внутрішніх зв'язків і кути між ними при жорсткому повороті;
- загальна зарядова/масова характеристика;
- повний набір фізично еквівалентних результатів за одночасного повороту джерела та детекторів.

## Тест

Побудувати `g_j` для H₂O, NH₃, CH₄, H₂SO₄ і кількох фіксованих `R`. Оцінити, чи відрізняє шість портів ці структури краще за 2D-проєкцію. Контроль: рандомні обертання та симетрична топологія з однаковим числом вимірів.
