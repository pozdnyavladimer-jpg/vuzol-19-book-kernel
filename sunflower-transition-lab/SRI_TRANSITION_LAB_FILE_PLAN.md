## Порядок показу експериментів

1. Розгортання трикутника: локальний контракт показує пошкоджений проміжний вузол.
2. Число та процес: компенсована помилка може зберігати правильну відповідь.
3. Активна пам’ять: відомий конфлікт змінює наступний пошук.
4. Gate цілої задачі: той самий соняшник має різні умови застосування.
5. Синтез: прогалина області → HOLD → нова гілка → повторна перевірка.

Код міститься в чотирьох каталогах `experiments/`. Окремі `tools/check_package.py` і `tools/reproduce.py` перевіряють пакет та відтворюють результати в тимчасових копіях. Первинний код експериментів збережено без змін.

## Перевірено

Усі чотири набори відтворено. Детерміновані результати збіглися; час і нестабільні діагностичні розміри repr не порівнювалися. Перевірено локальні посилання, структуру Markdown, 20 математичних блоків і 2 Mermaid-блоки. Рендеринг на опублікованій сторінці GitHub не виконувався.

Формат відповідає офіційним правилам: [математика](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/writing-mathematical-expressions), [діаграми](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/creating-diagrams).

Розпакуй архів перед додаванням папки в GitHub. Відкрий README, а потім `08_GITHUB_FORMATTING.md`, щоб перевірити вигляд формул у справжньому GitHub Preview.
