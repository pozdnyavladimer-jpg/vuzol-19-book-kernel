## Рівні готовності

| Компонент | Рівень |
|---|---|
| Локальні арифметичні контракти | Виконувані приклади |
| Пам’ять конфліктів | Реалізована в окремому пошуку |
| Відомий складений lift | Реалізований шаблон |
| Синтез послідовностей примітивів | Реалізований у скінченній мові |
| Виправлення coverage gap | Реалізований загальний конструктор спеціальної гілки |
| Спільний типізований runtime для всіх прикладів | Проєктування |
| Міжзадачний синтез довільних нових контрактів | Не встановлений |
| LLM як генератор кандидатів | Не тестувався |
| egg, Z3, факторний граф | Не реалізовані в цьому пакеті |
| Геометричний Sri3D / фізичні поля | Не моделювалися |
| Універсальна перевага над іншими підходами | Не встановлена |

## Найкраща черговість продовження

| Етап | Робота | Умова успіху |
|---|---|---|
| A | Спільна схема свідчень і версій | Жоден старий ALLOW не лишається чинним після зміни його підстав |
| B | Вибір між прямою програмою та виправленим макросом | Порівняно повну вартість, а не лише довжину запису |
| C | Перенесення знайдених макросів між прихованими задачами | Коректність на нових задачах із замороженим навчальним етапом |
| D | Порівняння зі звичайною мемоізацією та спеціалізованим індексом | Відокремлено внесок пам’яті, правила й індексу |
| E | LLM пропонує програму, перевіряльник незалежний | Виміряно false-ALLOW, HOLD, вартість і помилки самого аудитора |

Не треба спочатку будувати красивий 3D-інтерфейс. Спершу потрібні операції, передумови, інваріанти та перевірені переходи; інтерфейс має показувати їх.

## Критерії чесного порівняння

- Однакові примітиви, вхідні дані та облік бюджету.
- Точний кеш як окремий базовий режим.
- Нові задачі, а не лише повтори або перейменування.
- Підрахунок втрат правильних маршрутів через надмірні заборони.
- Витрати побудови макросу та перевірки пам’яті включено до ціни.
- Окремі метрики: запобігли хибному прийняттю / виявили його після прийняття.
- Перевірка спільної помилки генератора, контракту й аудитора.

## Межа фізичних аналогій

Для перевірки образу хвиль потрібні окремо визначені поле, рівняння, граничні умови, вимірювані величини та передбачення. Статус HOLD не є фізичною енергією, а пам’ять кандидата не доводить інтерференцію. Аналогія може спрямувати пошук моделі, але не замінює модель.
