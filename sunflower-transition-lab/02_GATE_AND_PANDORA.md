# 02 — Gate, Pandora та вимоги цілого

[План читання](README.md)

## Контракт цілого

Gate оцінює перехід щодо конкретної задачі. Потрібні не лише локальна структура, а й намір, бюджет, допустима похибка, область входів та тип гарантії.

```math
\mathrm{Door}=(\mathrm{source\_type},\mathrm{target\_type},
\mathrm{pre},\mathrm{transform},\mathrm{preserved},\mathrm{post},\mathrm{evidence}).
```

| Статус | Умова |
|---|---|
| ALLOW | Усі обов’язкові умови підтверджено в заявленій області |
| HOLD | Бракує даних, методу, покриття області або бюджету перевірки |
| BLOCK | Конкретну обов’язкову умову спростовано |

Якщо одна умова спростована, а інша невідома, кандидат отримує BLOCK із записом обох обставин. BLOCK перетворення не є NO задачі. NO допустиме після відповідного доказу або завершеного скінченного перебору.

## Pandora candidate та Pandora event

Pandora candidate зберігає можливість, яку чинний маршрут не може прийняти. Новий Gate може забезпечити іншу операцію, точніші передумови або перехід до ширшої області.

Pandora event — прийняття без чинних підстав. Така помилка може походити від неправильного контракту, пропущеної перевірки, застарілого кешу або дефекту перевіряльника.

```json
{
  "candidate_id": "reciprocal-route-v1",
  "decision": "HOLD",
  "reason": "coverage_gap",
  "excluded_but_required": ["0"],
  "reopen_condition": "Provide and verify a branch for x=0",
  "accepted_state_changed": false
}
```

Знайдений спосіб виправлення створює нову версію кандидата. Саме очікування не робить старий контракт правильним.

## Приклад із виконаного синтезу

```math
f(x)=\frac{x}{x+1},\qquad x\in\mathbb Q,\quad x\ne-1.
```

Знайдений шлях `inv → add1 → inv` має правильний вираз, але не виконується при x=0. А задача там визначена. Gate фіксує HOLD, а система додає перевірену гілку:

```math
g(x)=
\begin{cases}
0,&x=0,\\
\dfrac{1}{1/x+1},&x\ne0,-1.
\end{cases}
```

Заборону ділення на нуль не скасовано. Для допустимого входу побудовано інший маршрут. Цей макрос не доведений оптимальним: існує прямий шлях через 1−1/(x+1).

## Один соняшник — різні Gate

| Застосування | Глобальна умова | Що дозволено |
|---|---|---|
| Hitting Set | Вибрати не більше k елементів | Замінити k+1 пелюсток спільним ядром |
| Set Packing | Вибрати k неперетинних наборів розміру ≤d | Видалити пелюстку лише зі збереженням достатніх альтернатив |
| Точна логічна формула | Зберегти всі значення функції | Винести спільний множник |
| Наближена DNF | Похибка ≤ε у заданому розподілі | Замінити підформулу ядром після перевірки похибки |

Якщо змінюється задача або розподіл, старий ALLOW не переноситься автоматично.

## Зміна поля

Для рівнянь ax=b перехід від цілих до раціональних чисел додав 176 розв’язуваних входів у досліді з 289 входів. Але він не задовольняє задачу, яка прямо вимагає цілого результату. Розширення можливостей не скасовує початковий намір.

Образи ракової клітини, хвиль і гасіння використовуються в розмові як аналогії зв’язку локального процесу з цілим. Тут не задано біологічних чи фізичних рівнянь. Висновки про ці явища з цього коду не випливають.
