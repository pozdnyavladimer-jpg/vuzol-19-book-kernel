# Sri Transition Lab

Архітектура перевірених переходів: Flower → Sri → Gate → Bindu, активна пам’ять, Pandora та композиція контрактів.

Версія пакета: **0.1.0**. Дата пакета: **2026-09-17**. Мова документації: українська; ідентифікатори коду: англійські.

Це дослідницький пакет Vuzol-19 з виконуваними прикладами. Він показує, як зберігати причини переходів, перевіряти їх щодо цілої задачі та повертати незавершені кандидати до пошуку. Назви Sri3D, DNA-like route і octave — мова організації процесу; фізична модель ними не встановлена.

## Швидкий запуск

Потрібен Python 3.10 або новіший; сторонніх Python-пакетів немає.

```bash
python tools/check_package.py
python tools/reproduce.py --suite synthesis
python tools/reproduce.py --suite all
```

Команди виконуються з цієї папки. Відтворення працює у тимчасовій копії; початкові результати не перезаписуються. Новий звіт записується в `verification/`.

## Статус

Реалізовано окремі прототипи, а не єдиний Sri runtime. Немає LLM-викликів, реалізації egg/Z3, фізичного 3D або доказу гіпотези соняшника. Усі твердження про результати мають бути звірені з [каталогом свідчень](05_EXPERIMENTS_AND_EVIDENCE.md).
