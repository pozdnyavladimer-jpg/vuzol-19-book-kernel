# 00 — BOOT для людини та наступного ШІ

[План читання](README.md)

## Головна ідея

Перехід слід приймати лише разом із перевіреною областю застосування, підставами й відповідністю наміру цілої задачі. Пам’ять має змінювати наступний пошук, а не тільки зберігати текст попередньої відповіді.

Цей BOOT описує версію дослідницького пакета 0.1.0. Він не є новою редакцією всього World Theory та не засвідчує стан сторонніх репозиторіїв.

## Контракт читача

1. Спочатку зафіксуй задачу, типи входів, предметні обмеження та критерій завершення.
2. Відокремлюй бажану архітектуру, наявний код і результат конкретного експерименту.
3. Кандидатний стан не підміняє прийнятий стан.
4. ALLOW має область: певний вхід, клас входів, версію правил і тип гарантії.
5. BLOCK конкретного переходу не є доказом неможливості цілої задачі.
6. HOLD зберігає причину й умову повернення. Вичерпаний пошук не означає NO.
7. Після зміни підстав відкликай залежні свідчення та дозволи.
8. До порівняння швидкості включай пошук, аудит, пам’ять і побудову макроконтракту.
9. Не видавай геометрію, фізичну аналогію або числовий збіг за доказ алгоритму.
10. Перед твердженням «відтворено» запусти код або явно вкажи, що лише прочитав збережений результат.

## Словник

| Поняття | Значення у цьому пакеті |
|---|---|
| Signal | Питання, новий вхід, зміна підстав або виявлена невідповідність |
| Flower | Генерація альтернатив, повернення до пошуку та рух між кандидатами |
| Sri | Дев’ять ролей організації й аудиту переходу |
| Door | Типізований контракт зміни стану або представлення |
| Gate | Перевірка передумов і заявлених гарантій щодо цілої задачі |
| Bindu | Прийняте рішення з областю чинності та посиланнями на свідчення |
| Shadow | Конкретна невідповідність, контрприклад або брак свідчень |
| Pandora candidate | Збережена незавершена можливість із причиною та умовою повернення |
| Pandora event | Прийняття переходу без необхідних чинних підстав, тобто false-ALLOW |
| MemoryAtom | Запис переходу, його підстав, залежностей і можливого повторного використання |
| Octave | Рівень композиції: перевірений маршрут можна використовувати як оператор |
| Helix / DNA-like route | Впорядкована історія переходів, яка впливає на майбутній пошук |

У попередніх обговореннях Pandora мала різні значення. Тут `Pandora candidate` і `Pandora event` навмисно розділені. HOLD — статус кандидата; Pandora candidate — зміст запису. Одна назва не повинна приховувати різні операції.

## Що не можна приписувати цьому пакету

- Доказ загальної гіпотези соняшника або Collatz.
- Автоматичне відкриття довільних математичних законів.
- Реалізацію фізичного поля, інтерференції, свідомості або біологічної еволюції.
- Загальне прискорення O(N) до O(1), оптимальність 14/10/10/8 або стиснення RAM.
- Право на push, merge, оплату чи зміну доступу через обчислювальний ALLOW.

## Мінімальний підсумок роботи наступного ШІ

Вкажи: намір → обраний кандидат → виконані перевірки → статус і область → невирішене → зміна пам’яті → наступна перевірка. Не реконструюй уявну внутрішню історію моделі як нібито запис фактичного виконання.
