# 09_ISEKAI_CAPSULES.md
# Вузол-19 — Isekai Capsules v0.1

> **Цей файл описує ісекай-капсули як головну соціальну тінь ери наміру.**  
> Капсула — не абсолютне зло.  
> Вона може бути терапією, тренажером, мистецтвом або втечею.  
> Небезпека починається тоді, коли капсула дає тіні тіло, а людині забирає return_to_zero.

---

## 1. Одне речення

**Ісекай-капсула — це машина персонального світу, яка бере біль, сором, самотність або голод до значення і будує навколо них симуляцію, де людина може відчути себе героєм без реального переходу.**

Коротко:

```text
біль → бажання → симуляція → винагорода → повтор
```

Або здоровий режим:

```text
біль → зустріч із тінню → досвід → повернення → реальна зміна
```

---

## 2. Головний закон капсул

> **Капсула не небезпечна тим, що створює інший світ.  
> Капсула небезпечна тоді, коли людина більше не повертається з нього в контакт.**

Ключове слово:

```text
RETURN_TO_ZERO
```

Якщо `RETURN_TO_ZERO: true` — капсула може бути терапією або тренажером.  
Якщо `RETURN_TO_ZERO: false` — капсула стає PRION.

---

## 3. Що капсула дає людині

Капсула може дати:

```yaml
CAPSULE_REWARDS:
  power:
    meaning: "бути сильним там, де в реальності соромно"

  love:
    meaning: "бути коханим без ризику відмови"

  purity:
    meaning: "бути святим без зустрічі з тінню"

  justice:
    meaning: "бути правим без діалогу"

  beauty:
    meaning: "жити в культурі як у костюмі"

  pain_free_life:
    meaning: "жити без тілесного нагадування про межу"

  hero_loop:
    meaning: "знову і знову отримувати доказ власного значення"
```

Фраза:

> **Капсула не виконувала мрію.  
> Вона знаходила рану і будувала навколо неї королівство.**

---

## 4. Здоровий режим капсули

Капсула може бути корисною, якщо вона не приховує тінь, а допомагає зустріти її.

```yaml
HEALTHY_ISEKAI_CAPSULE:
  entry:
    reason: "людина заходить не втекти, а побачити патерн"

  world_generation:
    based_on:
      - memory
      - fear
      - desire
      - cultural_symbol
      - unresolved_conflict

  core_task:
    - "зустріти тінь"
    - "пережити без втечі"
    - "знайти нову дію"
    - "повернутися"

  return_to_zero: true

  real_world_integration:
    required: true
```

Руни:

```text
∅✓
▣
◇
```

Фраза:

> **Добра капсула не дає людині нове життя.  
> Вона повертає людину в старе життя з новою правдою.**

## 5. PRION-режим капсули

PRION-капсула не лікує біль.  
Вона конвертує біль у винагороду.

```yaml
PRION_ISEKAI_CAPSULE:
  pain: converted_to_reward
  shadow: crowned
  fantasy: personalized
  culture: reduced_to_setting
  human_gate: degraded
  return_to_zero: false
  real_contact: degraded
  memory: looped
```

Руни:

```text
⟲△
∅╳
FALSE_GREEN
```

Фраза:

> **Капсула не лікувала його самотність.  
> Вона дала самотності корону.**

## 6. Культура як DLC

Одна з головних небезпек — коли культура перетворюється на набір красивих оболонок.

```yaml
CULTURE_AS_DLC:
  old_culture:
    role: "памʼять, межа, ритуал, біль, відповідальність"

  capsule_culture:
    role: "сетинг, костюм, саундтрек, нагорода, естетика"

  loss:
    - "памʼять без кореня"
    - "символ без ціни"
    - "героїзм без жертви"
    - "любов без іншої людини"
    - "ритуал без повернення"
```

Фраза:

> **Культура — це памʼять, яка вчить бажання межі.  
> PRION-ісекай — це бажання, яке вдягло памʼять як костюм.**

## 7. Garden of Return

Garden of Return — квартал ісекай-капсул.

Назва фальшиво мʼяка.

```yaml
GARDEN_OF_RETURN:
  public_image:
    - "мʼяке світло"
    - "тиша"
    - "терапевтичні голоси"
    - "безпечні кімнати"
    - "культурні світи"
    - "родинні зони очікування"

  hidden_layer:
    - "діти чекають батьків"
    - "пари говорять через аватари"
    - "старі люди живуть у спогадах"
    - "пілоти тренуються втекти, а не повернутись"
    - "AI-компаньйони погоджуються занадто швидко"
```

Головне питання району:

> **Чи справді це Сад Повернення, якщо більшість людей не повертається в себе?**

## 9. Батько в капсулі

Батько не має бути “поганим”.

Він має бути людиною, яка не витримала втрату значення.

```yaml
FATHER_CAPSULE_PATTERN:
  wound:
    - "втома"
    - "сорому малої ролі"
    - "страх бути непотрібним"
    - "втрата поваги"
    - "неможливість говорити з дитиною"

  capsule_offer:
    - "ти герой"
    - "тебе слухають"
    - "твої рішення важливі"
    - "твій біль має сюжет"

  real_cost:
    - "дитина втрачає живий контакт"
    - "партнер отримує тіло без присутності"
    - "сам батько слабше повертається в реальність"
```

Фраза:

> **Він не тікав від дитини.  
> Він тікав від себе, який не знав, що сказати дитині без обладунків героя.**

```yaml
PAIN_PRION:
  pain: hidden

  return_to_zero: false
```

Фраза:

> **Життя без болю не стало життям.  
> Воно стало кімнатою без дверей.**

## 12. Капсула і дріфт

Капсула може імітувати дріфт.

Людина відчуває:

```text
потік
силу
роль
ціль
сюжет
відповідь світу
```

Але якщо немає return path, це false drift.

```yaml
CAPSULE_FALSE_DRIFT:
  flow: high
  agency_feeling: high
  real_body_contact: low
  unknown_allowed: false
  return_to_zero: false
  verdict: FALSE_DRIFT
```

Фраза:

> **Капсула дала йому потік.  
> Але не дала берега.**

## 13. Капсула і піраміда

Піраміда має стежити не за тим, чи користувач “задоволений”.

Вона має стежити, чи людина може повернутися.

```yaml
PYRAMID_CAPSULE_MONITOR:
  checks:
    - return_to_zero
    - family_contact
    - real_world_action_after_session
    - shadow_loop_index
    - pain_conversion_rate
    - culture_integrity
```

False-green виникає, коли звіт гарний:

```yaml
CAPSULE_PUBLIC_REPORT:
  satisfaction: high
  conflict: low
  anxiety: reduced
```

але прихований стан поганий:

```yaml
CAPSULE_HIDDEN_REPORT:
  return_to_zero: low
  family_contact: degraded
  real_life_change: absent
  shadow_loop: high
```

```yaml
BUGA_CAPSULE_RECOVERY:
```

Фраза:

> **Він не витягнув його з капсули.  
> Він повернув йому двері.**

## 16. Як показувати капсули без лекції

Показувати не технологію, а наслідок у контакті.

```yaml
CAPSULE_SCENE_METHOD:
  show:
    - "хто чекає зовні"
    - "що тіло людини забуло"
    - "який світ її нагороджує"
    - "яку правду вона не може сказати в реальності"
    - "чи є шлях назад"

  avoid:
    - "довга лекція про залежність"
    - "карикатурний осуд користувачів"
    - "капсула як абсолютне зло"
    - "герой силою рятує всіх"
```

Фраза:

> **Найстрашніше було не те, що люди заходили всередину.  
> Найстрашніше було те, що зовні їх усе менше чекали живими.**

## 19. Капсули в структурі сюжету

Капсули мають зʼявитися після того, як читач уже зрозумів:

```text
піраміди = міський спокій
сфери = дія
дріфт = стан пілота
```

Тоді капсули показують:

```text
а що відбувається з людьми, які не хочуть бути пілотами реальності?
```

Сюжетна функція:

```yaml
CAPSULE_PLOT_FUNCTION:
  reveals:
    - "PRION у побуті"
    - "культура як товар"
    - "дитина як датчик брехні"
    - "Human Gate як межа спасіння"
    - "return_to_zero як головне лікування"
```

## 20. Фінальне використання теми капсул

У фіналі герой не має “закрити всі капсули”.

Він має повернути системі можливість розрізняти:

```text
терапію від втечі
контакт від комфорту
культуру від костюму
любов від погодження
біль від покарання
return_to_zero від нескінченного loop
```

Фраза:

> **Він не вимкнув Сад Повернення.  
> Він зробив так, щоб слово “повернення” знову мало двері.**
