## 0. Purpose

This folder records one continuous experimental line.

The important result is not that every hypothesis survived. The important result is that the experiments progressively changed the object being searched for:

`fixed form → topology → overlap → alphabet → relational alphabet → reference frame → connection → holonomy → transition prediction`

The chain repeatedly rejected attractive but overly strong interpretations.

> A Gate may be better modeled as failure of the current transition/predictive model than as one fixed frequency, overlap ratio, phase defect, graph cycle, or top-two modal gap.

This is a research hypothesis, not an established physical law.

# I. PHYSICAL MEMORY AND TOPOLOGY — 217–222

## 217 — Material State / Memory

**Question:** Can a physical system retain transition history through material state?

**Result:** Yes in the ordinary physical sense: hysteresis, irreversible changes, defects and composition can make future response depend on history.

**Break:** A graph cycle is not required for physical memory.

**Verdict:** `ALLOW` history-dependent material memory. `BLOCK` “cycle = memory” as a universal rule.

## 218 — NiTi / Al-Cu: Loop vs Cascade

**Question:** Must memory be represented by a closed loop?

**Result:** No. NiTi supplies a useful hysteretic-loop example, while Al-Cu-like transformation/precipitation chains show that history can also be stored by a cascade.

**Break:**

`FLOW → GATE → COMMIT`

can continue either as

`COMMIT → HYSTERETIC LOOP → RETURN GATE`

## 227 — Wave Alphabet / Epistemic Transition Grammar

Candidate operators:

`QUIET, FLOW, SHADOW, GATE, BLOCK, COMMIT, UNWIND, REWRITE, QUERY`

**Question:** Are signed constructive/destructive operators enough to create a useful transition grammar?

**Result:** No. Positive-only and signed +/- alone performed essentially the same in the tested noisy reversal task. Improvement appeared when nonlinear/leaky Gate and reversible Unwind were added.

`positive-only ≈ 0.790`

`signed + Gate/Unwind ≈ 0.926`

A blind alphabet-size scan did not privilege 7.

**Break:** The useful object was not simply positive/negative signs; reversibility and state transition control mattered.

**Verdict:** `ALLOW` transition grammar. `HOLD` exactly nine runes. `BLOCK` seven states as established universal count.

Instead define a local predictive transition model:

`S_(t+1) ≈ F_B(S_t)`

with prediction residual:

`epsilon_t = ||S_(t+1) - F_B(S_t)||`.

Candidate interpretation:

`Bindu = currently stable predictive transition model`

`Shadow = systematic failure of that model`

`Gate = accumulated evidence that the old transition grammar is no longer locally valid`

`Unwind = invalidate dependencies/states supported by the failed grammar`

`Rewrite = learn a new local transition model`

This suggests experiment 237:

`PredictionError_t → ? → TopologyChange_(t+Δ)`

The decisive test is whether predictive residual rises **before** visible form change and adds held-out predictive information beyond simple form inertia, defects, modal gap and shuffled controls.
