# SCIENCE_THEORY_GATE.md
# Vuzol-19 Science Theory Gate

> Science Theory Gate protects the repository from turning metaphor into fact, model into proof, or prediction into action.
>
> It is used whenever a claim touches science, physics, chemistry, biology, medicine, climate, Earth, electron, molecule, body, brain, ancient technology or engineering.

Core rule:

> **A scientific claim may not cross from MODEL to FACT without validation.**

Short rule:

> **Formula. Prediction. Difference. Experiment. Failure condition.**

---

## 1. Why this Gate exists

Vuzol-19 contains strong symbolic models.

Some of them may be useful for:

```text
fiction
world theory
AI reasoning
scientific audit
hypothesis generation
scene writing
technology speculation
```

But a symbolic model is not automatically a scientific fact.

Science Theory Gate prevents:

```text
metaphor → fact
symbol → proof
pattern → diagnosis
simulation → physical law
AI prediction → truth
ancient image → technology claim
```

The Gate does not kill imagination.

It protects imagination from pretending to be validated reality.

---

## 2. Four-layer classification

Every science-touching claim must be separated into:

```text
FACT
MODEL
FICTION
HOLD
```

Definitions:

```yaml
FACT:
  meaning:
    - "measured"
    - "established"
    - "directly supported by evidence"
    - "accepted within stated conditions"
  rule:
    - "Do not add interpretation here."

MODEL:
  meaning:
    - "explanation"
    - "mechanism"
    - "hypothesis"
    - "mathematical or conceptual structure"
  rule:
    - "Model is not proof."

FICTION:
  meaning:
    - "narrative use"
    - "metaphor"
    - "symbolic extension"
    - "scene logic"
    - "worldbuilding"
  rule:
    - "Fiction may be useful but must not pretend to be fact."

HOLD:
  meaning:
    - "unknown"
    - "unvalidated"
    - "unsafe"
    - "premature"
    - "requires test"
  rule:
    - "HOLD protects truth."
```

Core sentence:

```text
HOLD is not failure.
HOLD is scientific honesty.
```

## 3. What is required to become TEST_ALLOWED

A claim can move from MODEL to TEST_ALLOWED only if it has:

```yaml
TEST_ALLOWED_REQUIREMENTS:
  1_formula:
    question: "Can the model be written as a formula, algorithm, mechanism or measurable structure?"

  2_prediction:
    question: "What does it predict?"

  3_difference:
    question: "How is it different from existing theory or existing explanation?"

  4_experiment:
    question: "Where can it be tested?"

  5_failure_condition:
    question: "What result would show that the model is wrong?"
```

If any part is missing:

```text
verdict = HOLD / MODEL_ONLY / FICTION_ONLY
```

## 18. Failure condition requirement

Every serious scientific model must say how it can fail.

```yaml
FAILURE_CONDITION:
  required: true
  asks:
    - "What observation would disprove this?"
    - "What experiment would block it?"
    - "What result would force revision?"
    - "What existing evidence already constrains it?"

  if_missing:
    verdict: "NOT_TESTABLE / HOLD"
```

Rule:

```text
A model that cannot fail cannot become science.
```

## 19. Difference from existing theory

A scientific model must say what it adds.

```yaml
DIFFERENCE_FROM_EXISTING_THEORY:
  asks:
    - "Does this predict something new?"
    - "Does this only rename existing explanation?"
    - "Does this conflict with known theory?"
    - "Does this reduce to known theory under normal conditions?"
    - "Where should the difference appear?"

  verdicts:
    no_difference:
      status: "INTERPRETIVE_LANGUAGE_ONLY"

    measurable_difference:
      status: "TEST_ALLOWED"

    conflicts_with_known_precision:
      status: "BLOCK_OR_REVISE"
```

Core sentence:

```text
If a model only renames known physics, it may be useful language, but not new physics.
```

## 22. Required wording levels

Use precise wording.

```yaml
WORDING_LEVELS:
  fact:
    allowed:
      - "measured"
      - "observed"
      - "established"
      - "supported by"
      - "confirmed within conditions"

  model:
    allowed:
      - "may explain"
      - "could model"
      - "is consistent with"
      - "suggests"
      - "hypothesis"

  hold:
    allowed:
      - "not yet validated"
      - "unknown"
      - "requires testing"
      - "cannot be claimed yet"
      - "attribution required"

  fiction:
    allowed:
      - "in the novel"
      - "as a metaphor"
      - "as worldbuilding"
      - "symbolically"
      - "scene logic"
```

Avoid:

```text
proves
definitely
guarantees
cures
explains everything
scientists will confirm
ancients had this technology
AI discovered truth
```

Unless there is actual evidence and a cited basis.

## 24. Minimal AI protocol

When asked about a scientific or quasi-scientific idea:

```text
1. What is actually known?
2. What is only model?
3. What is fiction/metaphor?
4. What remains HOLD?
5. Is there an octave jump?
6. Is there a formula?
7. Is there a prediction?
8. Is it different from existing theory?
9. Where can it be tested?
10. What would falsify it?
11. What is Bindu verdict?
```

If the claim is high-stakes:

```text
be more conservative
keep uncertainty visible
refer to qualified experts where appropriate
do not overclaim
```
