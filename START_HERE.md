## 1. What is this?

Vuzol-19 Book Kernel is a scene-runtime system for AI-assisted writing.

It helps writers, readers, researchers and AI builders check:

```text
intent
→ pressure
→ shadow
→ Human Gate
→ Flower Scan
→ Bindu Verdict
→ action / hold / block
→ memory update
```

This repository is not only a place to store chapters.

It is a working kernel for:

```text
writing scenes
testing theories
building AI tools
checking false-green
protecting Human Gate
teaching AI when not to generate
```

## 2. Choose your path

Start with one of four doors.

---

### Door 1 — I want to read the novel

Start here if you want the story first.

Read:

```text
27_CHAPTER_01_FULL_DRAFT.md
34_SCIENTIST_INTRO_SCENE.md
35_BUGA_FALSE_LIFT_TRAINING_SCENE.md
39_NOBEL_CHARACTER_DIALOGUE_TEST_SCENE.md
```

What to look for:

```text
Where is the pressure?
Where is the shadow?
Who has Human Gate?
What does the scene refuse to resolve too quickly?
What memory changes after the scene?
```

---

### Door 2 — I want to write a chapter

Start here if you want to contribute a scene or chapter.

Basic route:

```text
1. Choose a scene seed.
2. Fill PRE_SCENE_RUNTIME.
3. Run Flower Scan.
4. Produce Bindu Verdict.
5. Write the scene only after verdict.
6. Run Post Scene Audit.
7. Update Memory Ledger.
```

Required structure:

```text
PRE_SCENE_RUNTIME
SCENE
POST_SCENE_AUDIT
MEMORY_LEDGER_UPDATE
AI_WRITING_NOTE
```

Main rule:

> **Do not write a beautiful scene if Human Gate is missing.**

---

### Door 3 — I want to verify a theory

Start here if you want to separate fact, model and fiction.

Use:

```text
FACT
MODEL
FICTION
HOLD
```

Definitions:

```text
FACT    = what is confirmed or measurable
MODEL   = how Vuzol-19 interprets it through Flower runtime
FICTION = speculative or novel-world extension
HOLD    = not enough evidence / unsafe conclusion
```

Main rule:

> **Never present MODEL or FICTION as proven FACT.**

---

### Door 4 — I want to build the AI runtime

Start here if you want to build tools.

First target:

```text
Flower Decision Panel
```

Input:

```text
one intent
one scene request
one decision
```

Output:

```text
pressure
shadow
Human Gate risk
Nobel modes
Bindu verdict
smallest real action
```

Main rule:

> **The first useful AI tool is not one that writes faster.  
> It is one that knows when to say HOLD.**

## 3. First action

Do not start with the whole cosmology.

Start with one intent.

```text
Paste one intent.
Run Flower Scan.
See if it deserves COMMIT, HOLD or BLOCK.
```

Example:

```yaml
INPUT:
  intent: "I want to quit my project and start a new one."

FLOWER_DECISION_PANEL:
  pressure: "burnout + shame"
  shadow: "escape disguised as clarity"
  human_gate_risk: "decision made from exhaustion"
  nobel_mode: "SILENCE / HOLD"
  bindu_verdict: "HOLD 24h"
  smallest_real_action: "write one paragraph: what exactly hurts?"
```

## 4. The core runtime

```text
SIGNAL
→ FLOWER_SCAN
→ +3 / -3
→ SHADOW_AUDIT
→ NOBEL_MODES_SCAN
→ HUMAN_GATE_CHECK
→ BINDU_VERDICT
→ SCENE / HOLD / BLOCK / SILENCE / REPLACE
→ MEMORY_UPDATE
```

### +3 formation

```text
RED     = pressure / pain / potential
ORANGE  = flow / motion / expression
YELLOW  = structure / form / architecture
```

### -3 validation

```text
BLUE    = law / guard / tolerance / silence
GREEN   = stability / repair / attractor
VIOLET  = memory / phase / evolution
```

### Bindu verdicts

```text
COMMIT
HOLD
BLOCK
SILENCE
SUPPRESS
TOLERATE
VOID
FOLD
REPLACE
OCTAVE_SHIFT
```
