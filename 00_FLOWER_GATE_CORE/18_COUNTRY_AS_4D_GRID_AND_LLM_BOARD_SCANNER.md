## 3. LLM Board Scanner

An LLM must not be treated as an automatic decision-maker.

In this model, an LLM is a board scanner.

It scans a report, request, post, contract, incident, complaint, project, or policy as a 3/6/9 board.

```text
input document / report / case
→ 3V visible signal scan
→ 6V edge scan
→ 9V Gate scan
→ shadow scan
→ false-green scan
→ memory scan
→ verdict proposal
→ Human Gate
```

The AI proposes a transition verdict.

The AI does not own the final Gate.

Canonical line:

```text
AI scans the board.
Humans own the Gate.
Nature and Future must not be excluded from the verdict.
```

## 4. Multi-Block LLM Scan

A complex country-level transition should not be scanned by one flat prompt.

It should be scanned as layered blocks.

```text
Block 1 → pressure / visible pain
Block 2 → missing edges
Block 3 → document compatibility
Block 4 → role / operator ownership
Block 5 → legal / safety Gate
Block 6 → money / corruption Gate
Block 7 → Nature Gate
Block 8 → Future Gate
Block 9 → Bindu verdict
```

This prevents false-green.

One scan can miss the shadow.

Layered scans reduce blind spots.


```text
The grid is for repairing transitions, not controlling people.
```
