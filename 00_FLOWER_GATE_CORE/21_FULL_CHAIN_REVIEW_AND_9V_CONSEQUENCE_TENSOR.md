2. Why 9V Needs This Upgrade

A normal permission Gate asks:

Who approved this?
Is the owner known?
Is the rule satisfied?

But a consequence Gate asks deeper:

What will happen after this is approved?
What business state changes?
What safety state changes?
What recovery path is needed?
What memory must be written?
What shadow debt appears if this is wrong?
What future scan must learn from this transition?

Therefore:

9V = Gate + consequence + memory write

A Gate without consequence visibility can become false-green.

Example:

approved feature
but no rollback

approved payment
but no accounting memory

approved policy
but no appeal Gate

approved project
but no Nature Gate

approved AI output
but no Human Gate
