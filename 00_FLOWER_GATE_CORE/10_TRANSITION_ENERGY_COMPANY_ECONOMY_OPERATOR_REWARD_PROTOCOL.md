But money alone is too rough as a signal of correct transition.


```text

missing edge was closed
```

7. Document-as-Edge Economy

A document is not only a file.

A document is an edge that can open, close, block, repair, or verify a transition.

Examples:

| Document | Edge function | Gate opened | Hidden shadow if private |
|---|---|---|---|
| contract | customer promise → legal obligation | legal / finance / delivery Gate | one person controls the deal |
| invoice | completed obligation → payment | finance Gate | cashflow depends on private holder |
| specification | customer need → buildable task | engineering Gate | delivery becomes interpretation war |
| approval email | intent → authority | authority Gate | unclear owner, blame shifting |
| risk memo | unknown risk → visible decision | Guardian Gate | risk stays hidden until damage |
| meeting notes | spoken agreement → memory atom | memory Gate | same conflict repeats |
| rollback plan | action → safe reversal | safety Gate | action has no repair path |

A document has TE only when it becomes a usable edge.

Document TE checklist:

```text
owner exists
status is visible
freshness is known
authority is clear
linked Gate is named
risk is named
rollback exists when needed
memory trace exists after transition
```

If a document exists only in a private folder, private chat, or one person’s head, it is not a healthy edge.

Verdict:

```text
private document that controls flow = HOLD
visible document with authority and memory = OPEN candidate
```

10. Verdict Economy

Every transition receives a verdict before reward.

| Verdict | Meaning | TE result |
|---|---|---|
| OPEN | safe enough to proceed | TE may be awarded after outcome memory |
| ASK | human/role clarification needed | small TE for naming uncertainty |
| REPAIR | edge is broken but repairable | TE awarded for repair completion |
| HOLD | do not proceed yet | TE awarded if HOLD prevents false-green damage |
| BLOCK | transition is unsafe or invalid | TE awarded if block protects company from damage |

Important rule:

```text
Correct HOLD is value.
Correct BLOCK is value.
Correct REPAIR is value.
Only action is not the only value.
```

This is critical for AI-era economics.

AI makes action cheap.

Gate makes action meaningful.
