## 4. Virtual 3/6/9 Board

A virtual 3/6/9 board is created for a specific connection.

It is temporary.

It is not the full identity of either side.

It is the proposed board of this possible transition.

```text
3V = visible signal / request / offer
6V = route / edges / documents / operator connections
9V = Gate / authority / safety / policy / permission
```

### 4.1 3V Board

3V answers:

```text
What is visible?
What is being requested?
What is being offered?
What is the immediate signal?
```

Examples:

```text
"I want to test Flower Gate in a tire shop."
"I have a service point and need a better workflow."
"I am a master looking for a fair franchise."
"I can build the Android app."
```

## 5. Exchange Flow

Minimal runtime:

```text
1. Operator A prepares public packet.
2. Operator B prepares public packet.
3. Android / QR / NFC / local exchange transfers packet references.
4. AI boxes scan only allowed fields.
5. Each side builds a virtual 3/6/9 board.
6. Boards are compared.
7. Missing edges are detected.
8. Gate conflicts are detected.
9. False-green risks are detected.
10. Compatibility verdict is returned.
11. Humans decide whether to continue.
12. Memory atom records the exchange.
```

The AI must never silently convert compatibility into real commitment.
