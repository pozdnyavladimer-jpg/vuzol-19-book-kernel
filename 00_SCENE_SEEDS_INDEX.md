# Vuzol-19 — Scene Seeds Index v0.1

> **Scene seeds are not full scenes.**  
> They are pressure routes waiting for Flower Scan.

Use this folder when you want to write a new chapter, test a world mechanism, or give another writer/AI a clear starting point.

Core route:

```text
scene seed
→ PRE_SCENE_RUNTIME
→ Flower Scan
→ Bindu Verdict
→ scene draft
→ POST_SCENE_AUDIT
→ Memory Update
```

## How to use a scene seed

1. Pick a seed.
2. Copy it into a new chapter draft.
3. Fill `templates/PRE_SCENE_RUNTIME_TEMPLATE.md`.
4. Run Flower Scan.
5. Only draft after Bindu Verdict.
6. Audit with `templates/POST_SCENE_AUDIT_TEMPLATE.md`.

---

## Main rule

> **A scene seed is allowed to be mysterious.  
> It is not allowed to steal Human Gate.**
