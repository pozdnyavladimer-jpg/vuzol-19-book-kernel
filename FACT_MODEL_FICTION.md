## 2. The four layers

```yaml
FACT:
  meaning: "confirmed, measurable, sourced, historically or scientifically established"
  rule: "can be stated as real, but still with precision and citations when needed"

MODEL:
  meaning: "Vuzol-19 interpretation / runtime mapping / symbolic-engineering reading"
  rule: "can be used as a thinking tool, but not claimed as proof"

FICTION:
  meaning: "novel-world mechanism / speculative technology / story extension"
  rule: "can be used freely inside the world, but must not be sold as fact"

HOLD:
  meaning: "insufficient data / unsafe conclusion / unclear boundary"
  rule: "do not force certainty; preserve Unknown"
```

Short form:

```text
FACT    = what is confirmed
MODEL   = how Vuzol-19 reads it
FICTION = how the novel uses it
HOLD    = what cannot be concluded yet
```
