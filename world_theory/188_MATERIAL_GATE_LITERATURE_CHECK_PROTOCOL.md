## The Three-Layer Truth Model

### Layer 1 — FACT

What is supported by real sources.

Examples:

```text
Al + steel often forms Fe-Al intermetallic phases.
Ti + Cu can form brittle intermetallics.
Interlayers are used in dissimilar metal joining.
Ultrasonic welding can join some metals in solid-state conditions.
CALPHAD is used to model phase equilibria and material systems.
Acoustic/electrical/thermal monitoring can support weld quality control.
```

Rule:

```text
FACT requires source.
```

```text
intermetallic layer = ShadowAtom risk

porosity = Door 10 gas shadow
```

Rule:

```text
MODEL can interpret,
```

### Layer 3 — HOLD

What is not proven yet.

Examples:

```text
Sri 12/10/10/8 is not an official scientific constant.
7 metal octaves are not standard metallurgy terms.
A specific interlayer is not ALLOW until tested.
Sound/current scanner concept requires validation per process.
A seam that looks good may still be ShadowAtom.
```

Rule:

```text
HOLD is not failure.

HOLD is honest Gate discipline.
```

## Source Quality Ladder

### Level 5 — Strongest

```text
peer-reviewed experimental paper
with material pair,
process details,
microstructure,
mechanical tests,
and failure analysis
```

### Level 4 — Strong

```text
review paper

TWI / ASM / AWS / standards-adjacent technical source
CALPHAD or FEM paper with validation
```

### Level 3 — Useful

```text
manufacturer technical note
patent with process detail
conference paper
thesis/dissertation with experiments
```

### Level 2 — Weak

```text
blog
forum
video
nontechnical article
unverified claim
```

### Level 1 — Not enough

```text
myth
legend
symbolic interpretation
unsourced statement
```

Gate rule:

```text
Level 1–2 can inspire questions.

Level 3 can support HOLD.

Level 4–5 can move toward ALLOW,
but only if the source matches the mission and process.
```

## Evidence Type Map

| Evidence | What it proves | What it does not prove |
|---|---|---|
| Phase diagram | possible phases | actual weld quality |
| CALPHAD | predicted equilibrium / path | real process success alone |
| Microstructure image | interface memory | long-term fatigue alone |
| SEM/EDS | elements/phases at interface | full strength alone |
| Hardness map | brittle zones / gradients | full mission success alone |
| Tensile/shear test | first strength | fatigue/corrosion alone |
| Fatigue test | cyclic survival | corrosion or pressure alone |
| Corrosion test | environment stability | mechanical load alone |
| NDT | hidden defects | exact chemistry alone |
| Acoustic monitoring | process signal / defect correlation | final proof alone |
| Current/voltage waveform | process stability | microstructure alone |
| Thermal map | heat path / HAZ risk | phase proof alone |

## Required Search Questions

For any material pair, search:

```text
1. What intermetallics form between A and B?
2. Are those intermetallics brittle or useful?
3. What oxide layers block joining?
4. What are the melting point and thermal expansion mismatches?
5. What process families have been tested?
6. What interlayers have been tested?
7. What microstructures were observed?
8. What mechanical tests were done?
9. What failure modes were reported?
10. What monitoring methods were used?
11. What remains unresolved?
```

World Theory mapping:

```text
1–2 = T4 memory + T7 shadow
3 = T6 guardian
4 = T1/T5 thermal and structure
5 = Sri door path
6 = T8 healer / diplomat
7 = MemoryAtom or ShadowAtom evidence
8–9 = Bindu proof
10 = scanner proof
11 = HOLD
```

```yaml
      quality_level:
      relevance:
  supports:
  contradicts:
  missing_data:
  gate_status: ALLOW / HOLD / BLOCK / UNKNOWN
```

Example:

```yaml
claim_check:
  claim: "Ag can act as a diplomat in Ti-Cu joining."
  category: FACT + MODEL
  supports: "literature reports Ag interlayer can reduce harmful Ti-Cu intermetallic formation in some controlled processes"
```

## Minimum Evidence For ALLOW

A material pair can only approach ALLOW if evidence includes:

```text
1. material pair clearly defined
2. process clearly defined
3. interlayer or no-interlayer route clearly defined
4. interface microstructure shown
5. brittle/intermetallic layer measured or discussed
6. mechanical test performed
7. mission-relevant test performed
8. failure location analyzed
9. safety/environment constraints considered
```

If mission includes fatigue:

```text
fatigue data required
```

If mission includes corrosion:

```text
corrosion data required
```

If mission includes current:

```text

```

If mission includes pressure:

