## 2. Key Terms

### Metal Octave

A metal octave is not only a position in the periodic table.

It is the way a metal:

- conducts current
- stores or loses field memory
- vibrates mechanically
- reacts to magnetic field
- oxidizes
- forms phases and intermetallics
- accepts or rejects another material
- opens or blocks a Gate under heat, pressure, sound, and current

```text
Cu / Ag / Au = conductive octave family
Fe / Co / Ni = magnetic-domain octave family
Ti / Al / Si / Ca = structural octave family
Ga / In / Sn / Bi = soft / low-melting bridge family
Pt / Pd / Rh / Ru = catalytic Gate family
Pb / Hg / U / Pu = heavy shadow / dangerous Gate family
```

### Resonance State

Resonance is the “language state” of the material.

It depends on:

```text
element
+ alloy
+ shape
+ grain structure
+ temperature
+ stress
+ impurities
+ oxide layer
+ magnetic field
+ electric field
+ contact pressure
+ surrounding medium
```

There is no one universal frequency for a metal.

There is only a resonant Gate for a specific metal body in a specific state.

### Interlayer / Dopant / Filler

The interlayer is the translator between materials.

```text
material A = one kingdom
material B = another kingdom
interlayer = translator / diplomat / bridge
current = commit
sound = state scan
seam = new treaty of matter
```
