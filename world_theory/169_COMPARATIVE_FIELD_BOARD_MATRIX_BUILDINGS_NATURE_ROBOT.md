## 1. Core thesis

Buildings, organisms and robots can be compared as **field boards**.

```text
Architecture routes bodies, light, sound, water and pressure.
Nature routes water, ions, electrons, force and metabolism.
Robots route power, signals, pressure, sensors and actions.
```

Vuzol‑19 reads them through the same diagnostic questions:

```text
Where is the center?
Where are the ribs?
Where is the boundary?
Where is the Gate?
What is the current?
What is the output?
What becomes memory?
```

## 8. The false-green problem across domains

False-green means:

```text
local output looks correct,
but the transition chain is broken.
```

Examples:

```markdown
| System | False-green example | Missing Gate |
|---|---|---|
| Pyramid model | beautiful resonance claim without measurement | test Gate |
| Alhambra reading | aesthetic claim without spatial analysis | evidence Gate |
| Colosseum model | symbolic reading ignoring engineering | structure Gate |
| Leaf model | sacred geometry replacing biochemistry | mechanism Gate |
| Muscle model | force metaphor ignoring ATP/Ca²⁺ | biology Gate |
| Heart model | “blood coil” literalization | physics Gate |
| Robot model | movement demo without safety feedback | safety Gate |
| GitCube OS | generated code passes local test but breaks workflow | Human Gate / audit Gate |
```

Canon:

```text
Красива форма ще не означає чистий Gate.

Форма має пройти:
FACT
→ MODEL
→ HYPOTHESIS
→ TEST
→ HOLD / ALLOW / BLOCK.
```

  6_TEST:
