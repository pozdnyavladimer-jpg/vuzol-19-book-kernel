## 13. Three Essential Experiments

### Experiment A — Does memory change the next computation?

Before commit:

`X → H0 → Y0`

After a controlled commit, repeat the same `X`:

`X → H1 → Y1`

Test:

`Y1 ≠ Y0`

Then exclude temperature drift, sensor drift and other confounders.

### Experiment B — Does Gate improve stability?

Compare:

```text
System A: every candidate writes memory
System B: Gate filters candidates before commit
```

Measure performance, drift, energy per accepted update, state loss, reproducibility and useful memory lifetime.

Hypothesis:

`Stability_Gate > Stability_AlwaysWrite`

It must be allowed to fail.

### Experiment C — Does wave information control current-driven form?

Keep the current/energy protocol controlled and compare:

```text
A. intended wave pattern
B. distorted wave pattern
C. no wave-control pattern
```

Test whether:

`P(M_final | W_A, I) != P(M_final | W_B, I)`

If wave-pattern changes reproducibly alter committed material structure, the wave layer carries actionable spatial information.
