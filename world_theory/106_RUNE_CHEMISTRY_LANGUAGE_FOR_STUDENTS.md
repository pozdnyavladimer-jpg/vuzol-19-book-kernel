## Core Idea

A chemical element can be taught not only as a name, number, or formula.

It can also be taught as a transition role:

```text
element
→ rune-state
→ Gate condition
→ bond/contact
→ compound
→ memory trace
```

This file does not replace formal chemistry.

It adds a learning lens:

```text
Atom = node
Valence = door
Bond = edge
Reaction = Gate event
Compound = Bindu word
Phase = matter door
Catalyst = observer-process / Gate-helper
Unstable product = false-green structure
```

---

## Minimal Rune Formula

```text
A + B + △ + ◎✓ → ◉AB
```

Meaning:

```text
A and B are present.
The field has enough energy/pressure.
The reaction Gate opens.
A stable product appears.
```

If the Gate is not open:

```text
A + B + △ + ◎? → HOLD
```

Meaning:

```text
The reagents exist,
but a missing process prevents transition:
catalyst, heat, solvent, orientation, pressure, or correct field condition.
```

---

## Student Rule

Presence is not reaction.

Reagents can be present and still remain HOLD.

A reaction becomes real only when the missing process opens the Gate.

---

## Important Boundary

Runes are not evidence.

Runes are markers of what to check.

The real chemistry still requires:

- stoichiometry
- electron structure
- thermodynamics
- kinetics
- conditions
- experiment
- safety rules
