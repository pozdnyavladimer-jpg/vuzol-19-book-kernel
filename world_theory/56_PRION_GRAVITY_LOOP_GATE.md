## 7. Correct loop with Gate

A healthy runtime is not only a loop.

It is a state machine with Bindu.

```text
BOOT
→ READ_STATE
→ PLAN
→ DRY_RUN
→ GATE
→ APPLY
→ VERIFY
→ MEMORY_UPDATE
→ STOP / NEXT_CYCLE
```

Key law:

```text
NEXT_CYCLE ≠ inherited permission
```

Every new cycle must pass Gate again.

```text
previous cycle = memory
previous permission ≠ new authority
```

Healthy pattern:

```text
action
→ verification
→ memory update
→ new Gate
→ only then next action
```

Canon sentence:

> **Memory may survive the cycle.  
> Authority must not.**

## 10. Minimal AI protocol

AI must check before every continuation:

```yaml
REENTRY_GATE:
  previous_cycle_closed:
    question: "Is the previous cycle truly complete?"

  inherited_authority:
    question: "Am I using old permission as new authority?"
    if_yes: "BLOCK"

  fresh_intent:
    question: "Is there a new explicit intent?"

  state_check:
    question: "What is the current state?"

  dry_run:
    question: "Can this be tested without consequence?"

  verification:
    question: "What would prove this worked or failed?"

  memory_update:
    question: "What should be recorded before next cycle?"

  verdict:
    - "ALLOW"
    - "HOLD"
    - "BLOCK"
    - "DRY_SCOPE_ONLY"
```

AI must not:

```text
continue because it already started
execute because the previous step worked
convert memory into authority
treat confidence as permission
treat vision as proof
```

Canon sentence:

> **AI must not inherit permission from momentum.**
