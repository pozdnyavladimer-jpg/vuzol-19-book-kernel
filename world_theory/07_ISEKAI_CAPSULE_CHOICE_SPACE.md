# 07_ISEKAI_CAPSULE_CHOICE_SPACE.md
# Vuzol-19 — Isekai Capsule as Choice Space v0.1

> **The capsule is not automatically evil.**  
> It becomes dangerous when it removes return_to_zero.

---

## 1. Boundary

```yaml
FACT:
  - "Humans use stories, games, simulations and fantasies to explore possible lives."

MODEL:
  - "Vuzol-19 reads the capsule as simulated path chooser."

FICTION:
  - "In the novel, Isekai Capsule can become therapy, training, art or escape."

HOLD:
  - "Do not romanticize addiction or permanent escape."
  - "Do not call fantasy healing if real return is gone."
```

---

## 2. Healthy capsule

```yaml
HEALTHY_CAPSULE:
  allows:
    - "meet shadow"
    - "test possible path"
    - "feel consequence safely"
    - "return to body"
    - "make real-world small commit"

  requires:
    - "return_to_zero"
    - "Human Gate"
    - "AI Guard"
    - "memory update"
```

---

## 3. Dangerous capsule

```yaml
DANGEROUS_CAPSULE:
  signs:
    - "fantasy reward replaces real action"
    - "AI companion always agrees"
    - "body is forgotten"
    - "return path hidden"
    - "shadow gets a perfect world"
    - "real relationships degrade"
```
