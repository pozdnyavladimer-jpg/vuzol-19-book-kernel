## 1. Schrödinger Box

Schrödinger’s Cat is not proof that a literal cat is both alive and dead.

It is a thought experiment that shows a Gate problem:

```text
When does possibility become fact?
When does unknown become measured state?
When does HOLD become verdict?
```

In Vuzol-19:

```text
SCHRÖDINGER BOX = HOLD container for an unknown state
```

The unknown is not automatically true.

The unknown is not automatically false.

The unknown is placed in a container until interaction, measurement, experiment, coherence or consequence gives a verdict.

```text
unknown ≠ fact
unknown ≠ lie
unknown = HOLD
```

## 2. Shadow Box

The Shadow Box is the Vuzol-19 extension of Schrödinger’s Box.

```text
SHADOW BOX =
a container for unknown, unverified, non-coherent or dangerous possibility
```

Into the Shadow Box go:

```text
unverified theories
possible proteins
possible organisms
AI-generated structures
mythic explanations

dangerous technologies

```

The Shadow Box does not destroy them.

```text

The box is a Gate for the unknown.
```

## 3. The System Must Survive Without the Box

A strong theory does not require every shadow to be opened.

If the whole model collapses unless one unknown claim is forced into truth, then the model is weak.

```text
If the structure is alive without the unknown shadow,
the shadow can remain in HOLD.
```

If the shadow is real, it will start creating coherence.

If it is not real, the system will not need it to stay alive.

```text
If the shadow is alive,
it will begin to resonate.

If it is dead,
the structure will not depend on it.
```

## 4. Pandora Box

Pandora’s Box is different from Schrödinger’s Box.

```text
Schrödinger Box:
the form is still in possibility.
Verdict is not known.

Pandora Box:
the form is released.
Consequences can no longer be fully contained.
```

In Vuzol-19:

```text
PANDORA BOX = COMMIT without sufficient Gate
```

A Pandora event happens when a form leaves containment before:

```text
safety is known
edges are mapped
rollback exists
ecological role is understood
Human Gate is present
system-level consequences are evaluated
```
