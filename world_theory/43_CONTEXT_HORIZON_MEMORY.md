
```text
visible context = what the current page can still hold
context horizon = boundary where old text collapses out of view
dark memory = compressed meaning that still guides future steps
```

This is similar to the black-hole mechanism:


```text

```

## 9. Context PRION

A long conversation can develop PRION.

Context PRION happens when:

```text

new files duplicate old files
metaphor becomes claimed fact
beautiful language replaces structure
the index is not updated
the reader cannot find the route
```

Anti-PRION rule:

```text
Every large idea must become one of:
- canon file
- scene seed
- template
- index entry
- HOLD note
```

If it does not become one of these, it remains noise.

## 10. Practical compression protocol

When the page becomes too heavy, run this protocol:

```text
1. Stop adding new theory.
2. Identify the stable green idea.
3. Give it one file name.
4. Put it in the correct folder.
5. Add it to the index.
6. Add a short README pointer if needed.
7. Move on from raw conversation.
```

Do not try to preserve everything.

Preserve the mechanism.

---

## 11. Folder rule

Use folders as memory organs.

```text
world_theory/
  for canon mechanisms and large world logic

scene_seeds/
  for scenes and narrative demonstrations

templates/
  for repeatable checks and workflows

apps/
  for working interfaces and demos

memory/
  for transition atoms, logs, reports, state records
```

If a file is a scene, put it in `scene_seeds/`.

If a file explains a mechanism, put it in `world_theory/`.

If it does both, choose the primary function and cross-link it.
