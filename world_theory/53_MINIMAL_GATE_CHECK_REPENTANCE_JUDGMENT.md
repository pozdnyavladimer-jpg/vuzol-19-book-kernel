## 3. Translation: sin, repentance, judgment

### Sin

In ordinary language:

```text
sin = bad act / violation / guilt
```

In Vuzol-19 language:

```text
sin = shadow that became action without Gate
```

Formula:

```text
shadow
→ no Gate
→ action
→ damage
→ memory wound
```

### Repentance

In ordinary language:

```text
repentance = saying sorry / feeling guilty
```

In Vuzol-19 language:

```text
repentance = Human Gate returns
```

Formula:

```text
shadow
→ seen
→ named
→ HOLD
→ repair
→ green memory
```

Repentance is not humiliation.

It is re-entry into the correct transition path.

### Judgment

In ordinary language:

```text
judgment = punishment / condemnation
```

In Vuzol-19 language:

```text
judgment = verdict of transition compatibility
```

Judgment asks:

```text
can this state pass into the next octave?
or must it HOLD, repair, reroute, or stop?
```

So:

```text
judgment ≠ revenge
judgment = Gate verdict
```

## 12. Minimal algorithm

```python
def minimal_gate_check(intent, source_state, shadow, mechanism, consequence, memory):
    risk = score(shadow, consequence)
    stability = score(source_state, memory)
    clarity = score(intent, mechanism)

    if risk > 0.8:
        return "BLOCK"

    if risk > 0.5 and stability < 0.6:
        return "HOLD"

    if risk > 0.3:
        return "REPAIR_OR_SMALL_COMMIT"

    if clarity > 0.7 and stability > 0.6:
        return "ALLOW"

    return "REROUTE"
```
