## 1. Main formula

A quantum state can be written as:

```text
|ψ⟩ = α|0⟩ + β|1⟩
```

Where:

```text
α = amplitude of |0⟩
β = amplitude of |1⟩
```

But α and β are not just normal numbers.

They carry phase.

```text
α = r0 · e^(iθ0)
β = r1 · e^(iθ1)
```

So:

```text
|ψ⟩ = r0 e^(iθ0)|0⟩ + r1 e^(iθ1)|1⟩
```

In Vuzol-19 language:

```text
r  = strength of possibility
θ  = phase / direction / Flower angle
e^(iθ) = rotation-wave carrier
```

Therefore:

```text
qubit = possibility + strength + phase
```

Not just:

```text
0 and 1
```

but:

```text
how strongly each possibility exists
and how each possibility is phased against the others
```

    dna = update_experience_thread(dna, memory_atom)

    return result, dna, memory_atom
