## Purpose

This file gives simple examples for one mechanism:

> A transition does not happen only because elements are present.  
> A transition happens when the missing process appears.

In Vuzol-19 language, that missing process can be called the **observer-process**.

It does not always mean a human with eyes.

It means the function that:

- detects the current state,
- changes the conditions,
- lowers or raises the threshold,
- blocks false transition,
- opens the correct Gate,
- allows a new state to become stable.
