
## 6. Curie Gate

Curie temperature is the Gate at which a ferromagnetic material loses its long-range magnetic domain order.

Vuzol reading:

```text
Curie Gate = magnetic memory collapse threshold
```

Below Curie Gate:

```text
spin vectors
→ domains
→ domain memory
→ hysteresis
```

Above Curie Gate:

```text
thermal noise
→ domain order fails
→ ferromagnetic memory collapses
```

But not all memory disappears.

```text
magnetic memory may collapse
while structural, thermal, chemical, oxidation or deformation traces remain
```

Core phrase:

```text
Curie can erase magnetic memory,
but not necessarily material history.
```
