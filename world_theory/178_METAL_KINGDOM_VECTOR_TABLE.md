## Dissimilar Welding Reading

When two materials refuse to join, do not ask first:

```text
How much more heat?
```

Ask:

```text
Which kingdoms are fighting?
Which door is mismatched?
Which shadow appears at the interface?
Which interlayer can translate?
Which Gate window is safe?
```

Example pattern:

```text
Ti + Cu direct
→ structural clean hard kingdom meets soft current kingdom
→ risk: brittle Ti-Cu intermetallics
→ possible diplomat: Ag / Ni / graded transition
→ Gate: control temperature, time, diffusion, wetting, oxide
```

Another pattern:

```text
Al + steel
→ light oxide shell kingdom meets iron structural kingdom
→ risk: oxide + brittle Fe-Al intermetallics
→ possible diplomat: Zn, Ni, Cu, Ag, graded layers depending process
→ Gate: short heat input / pressure / controlled interlayer
```

| Porosity Shadow | gas trapped | shielding failure, vapor, moisture | gas control, drying, process stability |
| Diffusion Shadow | atoms do not cross enough | low time/temp/contact | diffusion bonding, pressure, interlayer |
| Wetting Shadow | molten phase refuses surface | surface energy mismatch | interlayer, flux, atmosphere control |
| Magnetic Shadow | field memory collapses | Curie Gate, domain disorder | temperature/field control |
| Acoustic Shadow | vibration mode not aligned | wrong frequency/shape/contact | scan resonance, tune pressure/frequency |
