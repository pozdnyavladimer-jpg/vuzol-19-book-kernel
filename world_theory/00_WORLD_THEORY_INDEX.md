
## 2. Core Terms

### Flower

The Flower is a graph of gated transitions.

```text
node = state / role / organ / repo / person / system
edge = possible transition
Gate = permission boundary
Bindu = verdict point
Memory = changed future graph
```

The Flower is not only an image.

It is a way to ask:

```text
What wants to pass?
What shadow does it carry?
Which Gate must check it?
What memory will remain after commit?
```

### Shadow

Shadow is the unaccounted consequence.

It may appear as:

```text
technical debt
trauma
waste
hidden dependency
false-green result
unreviewed AI action
burned material zone
social resentment
war pressure
climate debt
```

Shadow is not always evil.

Shadow is what was not integrated, measured, bounded, repaired or consciously accepted.

### Gate

Gate is the boundary condition that decides whether a transition may proceed.

Examples:

```text

test suite
law
membrane
contract
ethical limit
role permission
security policy
cooldown
operator approval
```

### Bindu

Bindu is the verdict point.

Possible verdicts:

```text
COMMIT
HOLD
ASK
REPAIR
BLOCK
ROLLBACK
OCTAVE_SHIFT
```

### Commit

Commit is when a transition enters reality.

In Git:

```text

```

In language:

```text

```

In life:

```text

```

In society:

```text

```

In material:

```text
solidified seam
```

### Memory

Memory is the trace left after commit.

A system without memory repeats shadow.
