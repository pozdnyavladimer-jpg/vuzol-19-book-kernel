## 5. Axis and meridians

The planetary axis is the central line of orientation.

It gives the planet a stable vertical reference.

```text
axis = central orientation
rotation = time rhythm
poles = vertical endpoints
equator = strongest horizontal belt
```

Meridians can be understood as vertical reading lines over the surface.

They connect pole-to-pole direction with surface position.

In this model:

```text
parallels / latitude lines = horizontal memory rings
meridians / longitude lines = vertical addressing routes
axis = central current reference
equator = horizontal resonance belt
poles = entry / exit thresholds
```

So the planet has two coordinate languages:

```text
horizontal rings:
  where memory spreads

vertical meridians:
  where transition is addressed
```

This does not mean literal electric current flows only along geographic meridians.

It means meridians are a useful symbolic grid for reading how vertical current can be addressed on a spherical plate.
