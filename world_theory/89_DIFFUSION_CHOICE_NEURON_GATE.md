When diffusion reaches a conscious Gate, it can enter several channels.

A practical five-channel model:


## 7. Neuron-Level Mirror

A neuron also shows the pattern.

This section is a **functional analogy**, not a complete neuroscience theory.

A neuron receives many inputs:

```text

inhibitory signals

network context
```

These inputs do not automatically become output.

They are integrated.

```text

membrane = Gate
excitatory input = pressure toward COMMIT
inhibitory input = HOLD / BLOCK force
threshold = Bindu-like boundary
action potential = spike / particle-event
```

Simplified model:

```text

→ integration
→ threshold check
→ spike or no spike
→ network consequence
→ plasticity changes future routing
```

In Vuzol-19 language:

```text

```

The spike is not the whole thought.

The spike is a local commit inside a much larger field.
