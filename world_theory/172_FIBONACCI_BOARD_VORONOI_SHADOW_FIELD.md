## 4. Voronoi as Edge Formation Analogy

Voronoi tessellation is a strong geometric analogy for the birth of edges.

If several sources expand at the same time:

```text
source A expands
source B expands
source C expands
```

then their fronts eventually meet.

Where the expansion fronts balance, a boundary appears:

```text
A front ↔ B front
= edge
```

Vuzol‑19 reading:

```text
edge is not a decorative line.

edge is a memory of solved collision.
```

Ukrainian:

```text
Ребро — це не намальована лінія.

Ребро — це памʼять вирішеного зіткнення.
```

Therefore:

```text
Voronoi edge = place where two growth fields could not both continue.
```

## 6. Four Types of Shadow

### 6.1 Boundary Shadow

This is constructive Shadow.

A stable edge always excludes some directions.

```text
successful boundary
→ route excluded
→ form becomes possible
```

Canon:

```text
Every stable form has a boundary shadow.
```

Ukrainian:

```text
Кожна стабільна форма має тінь межі.
```

---

### 6.2 Overload Shadow

This appears when the edge cannot hold the pressure of a neighboring vector.

```text
edge formed
→ pressure exceeds tolerance
→ edge bends / cracks / drifts
→ ShadowAtom appears
```

Examples:

```text
cracked dome rib,
overloaded team,
broken API dependency,
corrupted operator edge,
forest cut without planting edge.
```

---

### 6.3 Exhaustion Shadow

This appears when growth stops too early because the system lacks current, material, time, trust, or medium.

```text
growth begins
→ current is insufficient
→ route freezes
→ unfinished form remains
```

This is the shadow of unrealized possibility.

Ukrainian:

```text
Тінь виснаження — це недорощена можливість.
```

---

### 6.4 False-Green Shadow

This is the most dangerous Shadow.

A zone looks stable, but hidden pressure was not integrated.

```text
visible green
→ hidden pressure remains
→ delayed failure
```

Examples:

```text
tests pass but business process is broken,
profit rises but team burns out,
contract exists but operator edge is missing,
forest planting documented but trees do not survive.
```

Canon:

```text
False-green is a stable-looking zone
whose Shadow was not paid.
```

Ukrainian:

```text
False-green — це зона,
яка виглядає стабільною,
але її тінь не була оплачена.
```
