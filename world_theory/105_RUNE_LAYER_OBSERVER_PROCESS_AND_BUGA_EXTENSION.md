# 1. Rune syntax levels

A rune may mark one of five layers:

```text
[S] Signal layer
[Ψ] Pomysel / inner candidate layer
[Θ] Shadow / risk layer
[▣] Gate / permission layer
[◉] Bindu / verdict / memory layer
```

Short example:

```text
[S] → [Θ] → [Ψ] → [▣] → [◉]
```

Meaning:

```text
Signal enters.
Shadow filters it.
Pomysel arises.
Gate tests it.
Bindu returns verdict.
```
