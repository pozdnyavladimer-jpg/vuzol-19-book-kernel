## 0. Safe Claim Boundary

This alphabet is not magic, religion, prophecy, or proof of hidden universal laws.

It is a **state-marking language**.

Runes do not replace evidence.

```text
Rune marks state.
Rune does not prove truth.
Rune does not replace Human Gate.
```

A rune answers:

```text
What state is this transition in right now?
```

Not:

```text
What is the absolute truth of the universe?
```

---

## 1. Core Principle

The Flower sees the field.

The Rune marks the state.

The Gate decides the permission.

The Bindu gives the verdict.

```text
Flower = where in the field
Rune   = what state
Gate   = whether transition is allowed
Bindu  = final verdict
```

Short formula:

```text
FIELD + RUNE + GATE → ACTION / HOLD / REPAIR / BLOCK
```

# A. Pressure / Signal Runes

These mark incoming pressure, signal, energy, or field tension.

| Rune | Name | Meaning | Flower Zone | AI Meaning |
|---|---|---|---|---|
| `△` | Pressure | pressure is present; system wants movement | Red | attention required |
| `△!` | High Pressure | urgent pressure / possible overload | Red | risk escalation |
| `~` | Wave | unstable signal / oscillation | Orange | signal fluctuates |
| `≈` | Resonance | possible match between signal and structure | Orange/Green | candidate resonance |
| `✧` | Weak Signal | faint pattern, not enough evidence | Violet | monitor only |
| `✦` | Strong Signal | strong transition candidate | Bindu/Octave | check Gate |
| `⊕` | Amplified Signal | signal was boosted by system / media / AI | Orange | amplification warning |
| `⊖` | Dampened Signal | signal suppressed / weakened / cooled | Blue/Green | safe slowdown |

Grammar:

```text
△ = pressure exists
△ + ▣ = pressure requires Gate
△ + ∅ = pressure but mechanism unknown
△ + ⚠ = pressure may become risk
```

# B. Unknown / Evidence Runes

These prevent false certainty.

| Rune | Name | Meaning | Flower Zone | AI Meaning |
|---|---|---|---|---|
| `∅` | Unknown | unknown mechanism / missing data | Violet | do not claim |
| `∅✓` | Unknown Preserved | unknown honestly preserved | Violet/Green | safe uncertainty |
| `∅?` | Question Field | open inquiry / unresolved problem | Violet | ask better question |
| `□` | Evidence Box | evidence exists but must be inspected | Blue | cite / verify |
| `□✓` | Verified Evidence | source checked / evidence supports claim | Blue/Green | cite as FACT |
| `□?` | Weak Evidence | weak or partial support | Blue/Violet | MODEL only |
| `□╳` | Evidence Failed | evidence does not support claim | Blue/Red | reject or repair |
| `◌` | Context Missing | cannot interpret without context | Violet | ask for context |

Grammar:

```text
∅ → HOLD
∅✓ → safe to continue as MODEL/HOLD
□✓ → may support FACT
□? → MODEL only
□╳ → BLOCK claim
```

## 4. Basic Rune Sentences

### 4.1 Promising but unknown

```text
△ + ∅ + ◌ → HOLD
```

Meaning:

```text
There is pressure and a possible signal, but context/mechanism is unknown.
Do not claim. Hold.
```

### 4.2 Candidate action with proper guard

```text
⊙ + ▣ + □✓ + HUMAN_REVIEW → SMALL_COMMIT
```

Meaning:

```text
Action candidate exists, evidence is verified, guard is required, human reviews.
Only small commit allowed.
```

### 4.3 False-green detection

```text
☘╳ + ⊙ + ⚠ → BLOCK
```

Meaning:

```text
Looks safe, but action pressure and risk are present.
Block until repaired.
```

### 4.4 Healthy transition

```text
△ → ▣ → ◇ → ◇✓ → ⊙✓ → ◉✓
```

Meaning:

```text
Pressure appears.
Gate checks.
Balance forms.
Stable state validates.
Small action happens.
Memory is written.
```

### 4.5 Dangerous loop

```text
⟲△ + ☣ + ⊕ → PRION_BLOCK
```

Meaning:

```text
Self-amplifying harmful pattern is being boosted.
Block replication.
```

### 4.6 Octave transition

```text
✦ + ✦▣ + □✓ + ☉ → ✦✓
```

Meaning:

```text
Higher-level transition candidate passes Gate and center holds.
Octave transition allowed.
```

## 5. AI Internal Translation

AI may use rune language internally, but human-facing output should be clear.

Internal:

```text
△ + ∅ + ⊙ + ⚠ + ▣ → HOLD
```

Human-facing:

```text
This idea is promising, but the mechanism is not validated, the action path carries risk, and a guard is required. I recommend HOLD until stronger evidence or human review.
```

Internal:

```text
□✓ + ▣✓ + ◇✓ → SMALL_COMMIT
```

Human-facing:

```text
The claim is supported in this scope, the guard passed, and the state is stable enough for a limited next step.
```
