## 1. Головний принцип технологій

Технологія у “Вузлі-19” не є магією.

Вона не замінює людину.  
Вона читає стан, підсилює дію, блокує ризик або відкриває шлях.

```text
людина = намір / Human Gate
Квітка = перевірка стану
технологія = тіло дії
Guard = межа
памʼять = наслідок
```

Головне правило:

> **Технологія не має права виконувати тінь швидше, ніж людина встигає її побачити.**

## 3. Pyramid Node / Пірамідальний вузол

### 3.1. Роль

Піраміда — це не храм і не декор міста.

Піраміда — це **міський стабілізатор наміру**.

Вона тримає:

```text
такт міста
польову синхронізацію
інфраструктурний Guard
ритм транспорту
VR-шари
сфери Буга
громадські капсули
енергетичну рівновагу
```

### 3.2. Як працює в сцені

```yaml
PYRAMID_NODE:
  reads:
    - city_pressure
    - social_noise
    - drift_load
    - capsule_density
    - public_emotion
    - AI_runtime_activity

  outputs:
    - field_clock
    - stability_signal
    - guard_schema
    - local_rune_overlay
```

### 3.3. False Green піраміди

Піраміда може брехати не тому, що вимкнулась, а тому що стала надто стабільною.

```yaml
PYRAMID_FALSE_GREEN:
  visible:
    - calm_city
    - low_conflict
    - smooth_transport
    - therapeutic_language
  hidden:
    - pain_suppressed
    - unknown_blocked
    - human_gate_degraded
    - return_to_zero_missing
```

Руна:

```text
△
FALSE_GREEN
∅╳
```

Фраза:

> **Коли піраміда бреше, місто не кричить.  
> Воно стає надто тихим.**

## 7. Buga Sphere / Сфера Буга

### 7.1. Роль

Сфера Буга — це **remote body**.

Вона може бути:

```text
транспортом
дослідницьким тілом
ремонтним тілом
підводним апаратом
аварійним мостом
бойовим ризиком
інструментом дріфту
```

Але до підключення вона ще не є “тілом”.

```text
сфера на станції ≠ тіло
сфера + пілот + дріфт + Guard = дія
```

Фраза:

> **Сфера не була тілом.  
> Вона ставала тим, що в пілоті проходило через неї.**

## 8. Drift System / Дріфт

### 8.1. Що таке дріфт

Дріфт — це не “керування силою думки”.

Дріфт — це стан, де:

```text
людина
машина
поле
намір
Guard
return path
```

на короткий час стають одним маршрутом.

Фраза:

> **Дріфт починається там, де пілот перестає змушувати машину і дозволяє їй стати тілом без втрати Human Gate.**

### 8.2. Хто не може дріфтити

```yaml
DRIFT_BLOCKERS:
  - shadow_has_motor_access
  - unknown_blocked
  - intent_force_too_high
  - control_disguised_as_balance
  - pain_suppressed
  - return_path_missing
```

### 8.3. Хто може дріфтити

```yaml
DRIFT_PILOT:
  can:
    - hold_unknown
    - feel_pressure_without_panic
    - reduce_intent_force
    - preserve_human_gate
    - detect_false_green
    - accept_body_signal
```

## 12. Як технології зʼявляються в побуті

Світ живий, коли технології є не тільки в битвах, а в малих сценах.

| Побут | Технологія | Що показує |
|---|---|---|
| людина хоче збрехати близькому | Personal Node + VR HUD | слово теж є commit |
| студент обирає сферу | Buga Sphere + exoskeleton | сила без Guard стає зброєю |
| місто занадто спокійне | Pyramid Node | false-green на рівні інфраструктури |
| батько сидить у капсулі | Isekai Capsule | тінь отримала світ |
| бабуся говорить із вузлом | Personal Node | технологія може бути мʼякою |
| дитина в школі вчиться мовчати | Unknown Protocol | освіта ери наміру |
| AI пише код | AI Guard + Memory Ledger | код може бути misfold |
| пілот подорожує сферою | Drift System | рух без втрати центру |
